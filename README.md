# SEC Financial Statements

An exploratory data analysis (EDA) project using financial statement data published by the U.S. Securities and Exchange Commission (SEC).

---

## 📌 Project Overview

This project explores SEC financial records to identify patterns in financial values, accounting concepts, companies, filing types, and reporting periods.

---

## 🔍 Key Research Areas

- Distribution of financial values
- Frequently reported accounting concepts
- Company-wise financial records
- 10-K vs 10-Q filing distribution
- Reporting-period patterns
- Missing financial values

---

## 📊 Dataset

| Detail | Description |
|---|---|
| **Source** | SEC Financial Statement Data Sets |
